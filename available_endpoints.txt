=====================================================
FRONTEND INTEGRATION EXAMPLES
=====================================================

JavaScript/TypeScript Implementation:

// Basic Workflow
async function basicDrumAnalysis(videoFile) {
  // Step 1: Upload
  const formData = new FormData();
  formData.append('file', videoFile);
  const upload = await fetch('/api/videos/upload', {
    method: 'POST',
    body: formData
  });
  const uploadResult = await upload.json();

  // Step 2: Analyze
  const analysis = await fetch(`/api/videos/analyze/${uploadResult.video.id}`, {
    method: 'POST'
  });
  return await analysis.json();
}

// Enhanced Workflow
async function enhancedDrumAnalysis(videoFile) {
  const upload = await uploadVideo(videoFile);
  const videoId = upload.video.id;

  // Separate sources
  await fetch(`/api/videos/${videoId}/separate-sources?method=spectral`);

  // Enhance drums
  await fetch(`/api/videos/${videoId}/enhance-drums?drum_type=all&enhancement_strength=0.4`);

  // Final analysis
  const analysis = await fetch(`/api/videos/analyze/${videoId}`, { method: 'POST' });
  return await analysis.json();
}

=====================================================
AUDIO PROCESSING PARAMETERS
=====================================================

Source Separation Methods:
- "spectral" (recommended): Fast spectral masking
- "nmf": Non-negative Matrix Factorization
- "ica": Independent Component Analysis (requires stereo)

Enhancement Types:
- "kick", "snare", "hihat", "cymbals", "toms", "all"

Export Formats:
- Audio: "wav", "flac", "aiff"
- Bit Depth: 16, 24, 32

Video Formats Supported:
- .mp4, .avi, .mov, .mkv, .webm

Audio Formats Supported:
- .wav, .mp3, .flac, .m4a, .ogg

NOTES & REQUIREMENTS
=====================================================

1. Port 8000: Full-featured backend with complete workflow
2. Port 8001: Specialized ML backend for advanced analysis
3. FFmpeg required for video/audio processing
4. All API endpoints support CORS for frontend integration
5. File uploads use multipart/form-data format
6. Video ID-based endpoints work with uploaded files only
7. Direct analysis endpoints work with any file upload
8. Processing is done server-side with real-time feedback
9. Demo mode available for testing without full setup
10. Professional workflow requires more processing time but yields better results

For development: Use basic workflow (Steps 1-2)
For production: Use enhanced workflow (Steps 1-5)
